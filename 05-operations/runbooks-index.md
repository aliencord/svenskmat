## Purpose

This section should contain operational runbooks for repeated or high-risk tasks.

## Priority Runbooks To Create

- Production incident response
- Service restart and rollback
- Deployment failure response
- Access provisioning and deprovisioning
- Backup and restore
- Third-party outage handling

## Runbook Rules

- Each runbook should be actionable under pressure.
- Include pre-checks, exact actions, rollback steps, and escalation points.
- Link dashboards, logs, repos, and external vendors where relevant.
