## Security Objectives

- Protect customer and company data.
- Reduce likelihood and impact of incidents.
- Build secure defaults into engineering and operations.

## Security Workstreams

- Asset inventory
- Access control
- Secrets management
- Vulnerability management
- Logging and monitoring
- Incident response
- Vendor and integration review
- Backup and recovery

## Minimum Control Baseline

- MFA enforced for critical systems
- Centralized secrets handling
- Access review cadence
- Dependency update process
- Backup verification
- Audit logging for sensitive systems
